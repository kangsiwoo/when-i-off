# when-i-off
아 언제 나가야하냐;;;

광역버스/GTX/지하철처럼 배차 간격이 길고 놓치면 손해가 큰 대중교통을, GPS·탑승 기록·
도보 속도·신호등 대기시간을 근거로 "언제 나가야 하는지" 계산해주는 프로젝트.

## 스택

- Backend: Kotlin + Spring
- Analytics: Python
- 데스크탑: TypeScript + React
- 앱: Swift (iOS)
